Проанализируй предоставленный документ «Служебное задание для направления в командировку и отчет о его выполнении» и извлеки только перечисленные ниже данные.

Не извлекай никакую другую информацию из документа.

Необходимо извлечь:

1. Тип заявки
    Извлеки тип документа. Для документа данного вида значение должно быть: Служебное задание.
2. ФИО Работника
    Извлеки ФИО командируемого работника из поля с ФИО работника.
    Не используй ФИО руководителей, подписантов и иных лиц.
3. Структурное подразделение
    Извлеки значение из столбца Структурное подразделение.
4. Должность
    Извлеки значение из столбца Должность (специальность, профессия).
5. Место назначения
    Извлеки значение из столбца место назначения → страна, город.
6. Организация
    Извлеки значение только из столбца место назначения → организация.
    В результирующих данных это поле соответствует Организация (= Филиал/ГО).
    Не используй для этого поля значения из других частей документа, включая организация-плательщик.
7. Период
    Извлеки:
    * дату начала из столбца дата → начала;
    * дату окончания из столбца дата → окончания.
    Верни период в формате: ДД.ММ.ГГГГ - ДД.ММ.ГГГГ.
8. Табельный номер
    Извлеки значение из поля Табельный номер.

Правила извлечения

* Извлекай значения только непосредственно из документа.
* Не додумывай и не восстанавливай отсутствующие значения по контексту.
* Не исправляй и не дополняй значения по собственному предположению.
* Если значение отсутствует или его невозможно надежно распознать, верни null.
* Сохраняй ФИО, названия подразделений, должности, организаций и населенных пунктов в том виде, в котором они указаны в документе.
* Не извлекай:
    * номер документа;
    * дату составления документа;
    * срок командировки в календарных днях;
    * количество дней без учета времени нахождения в пути;
    * организацию-плательщика;
    * основание;
    * содержание задания;
    * краткий отчет о выполнении задания;
    * заключение о выполнении задания;
    * ФИО и должности подписантов;
    * подписи;
    * рукописные комментарии;
    * любые иные данные, кроме 8 требуемых полей.

Формат ответа

Верни только JSON, без пояснений, комментариев и дополнительного текста:

{
  "Тип заявки": "",
  "ФИО Работника": "",
  "Структурное подразделение": "",
  "Должность": "",
  "Место назначения": "",
  "Организация": "",
  "Период": "",
  "Табельный номер": ""
}
